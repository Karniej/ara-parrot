Ara's first launch used to be three minutes of nothing happening. This release is mostly about explaining that wait, and about ara looking like one product on both platforms.

## New

**A first-run window that says what it is doing.** A fresh install has to collect two permissions, download a 1.6 GB model, and let macOS compile that model for this machine. Ara has no Dock icon and no window, so launched from Finder all of that happened in silence — indistinguishable from an app that does not work. There is now a window: the microphone, then accessibility, then the download with a percentage, then the compile with a clock and the one sentence that matters, which is that quitting starts it over.

The accessibility step ends in ara restarting itself. macOS decides a process's accessibility trust when it starts, so a grant given to a running process does nothing until the next launch — which is why `ara setup` has always told you to run the command again. A window cannot ask that of someone who has never opened a terminal.

**It is not only the first run.** The compile is cached against the app's signing identity as well as the macOS build, so installing a new version of ara pays it again. That launch now opens the same window to explain itself, without taking the foreground — by then you have gone back to work, and it has nothing to ask you for.

**The window is honest about what it cannot see.** Both permissions and the model on disk are read live, so revoking a permission brings the window back rather than leaving a daemon that cannot work and cannot say why. Only the compile is remembered, because nothing on disk can be read to answer it.

## Changed

**Ara looks like the iOS app now.** The two shipped as one product and looked like two. The palette, the serif display face, the monospaced labels and the parrot mark are the iOS app's, ported rather than re-drawn — the mark's outlines are the same curves. The rules came with them: amber marks the live microphone and nothing else, which is why the progress bars in the setup window are deliberately grey.

**The menu bar shows ara's own bird.** It was a generic line-art bird from an icon set. It is the app icon's parrot now, and it turns amber while you are recording.

## Fixed

**Starting a second dictation no longer takes the first one's indicator with it.** Speak, pause, and start speaking again while the first utterance is still being transcribed: ara captured everything correctly and delivered both, but the moment the first transcript landed, the recording pill for the one you were in the middle of disappeared and the menu bar went back to idle. The daemon was still listening and had no way to say so. Every recording now owns the screen until something newer takes it.

**A warm start is about half what it was.** Measured on an M3 Pro, `listening on` now prints within 10ms of the model becoming ready, where it used to wait out a five-second timer belonging to the warm-up ladder — a timer that had already decided to do nothing. The failure path still waits for it, because that is the one case where the answer matters.

## Measured

The Neural Engine against the GPU, same machine, same audio, one session:

| audio encoder  | warm load | per utterance |
|---|---|---|
| Neural Engine  | 1.7 s     | 0.49–0.56 s   |
| GPU            | 6.5 s     | 1.23–1.33 s   |

Running the encoder on the GPU skips the multi-minute compile entirely, and this is why it does not: two and a half times the cost on every utterance, forever, to avoid a wait that happens once per install. Loading both — dictating on the GPU copy while the Neural Engine copy compiles behind it — was considered and rejected on memory. It holds the model twice.

## Still broken

**Local cleanup gives up on long transcripts.** Unchanged from 0.3.0.

**Whisper repeats itself on long audio.** Unchanged from 0.2.0.

**Language detection can flip on a long utterance.** Unchanged from 0.2.0.

## Install

Download, open the DMG, drag Ara to Applications. Unsigned, so the first launch needs right-click → Open.

The first run compiles the model for your Mac, which takes a few minutes. The window now tells you that is what is happening, and it is worth waiting out: quitting partway through throws the whole compile away.
