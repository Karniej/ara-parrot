Ara transcribes about five times faster than it did, and stops rewriting text that no longer needs rewriting. On a 34-second dictation the wait between releasing the key and seeing words went from 3.2 seconds to under half a second.

## Changed

**Parakeet is the new default transcriber.** Measured on an M3 Pro, both models in one process, against real dictation rather than a synthesized voice:

| | Parakeet | Whisper | |
|---|---|---|---|
| 34.6 s of English | 380 ms | 1674 ms | 4.4× |
| 29.3 s of Polish | 413 ms | 1991 ms | 4.8× |
| model load | 336 ms | 1540 ms | 4.6× |

Both transcripts were correct in both languages, so the speed is the whole difference — and it is the part you feel, because that wait is most of the delay between speaking and seeing text.

**Whisper is still here, and still supported.** Parakeet covers 25 European languages; Whisper covers 99. Polish, Czech and Ukrainian are in; Japanese, Chinese, Korean, Arabic, Hindi and about sixty-five others are not. If you dictate in one of those, pick Whisper — the first run now asks, and the Model submenu still offers both.

**Cleanup is off by default.** Parakeet punctuates and capitalises its own output, which is what the old default was paying a language model a second per utterance to do. The rules floor still runs: filler words are still stripped, your dictionary still corrects, snippets still expand. What is off is the *language model*.

That also means the `email`, `chat` and `code` modes do nothing at the default setting, because rewriting is all they are. Set `"cleanup": "medium"` — or answer "tidy it up" in the first-run window — and they come back.

Ara also stops loading the 0.9 GB formatting model when nothing can call it. Resident memory at startup fell from 454 MB to 135 MB.

## New

**The first run asks two questions.** Which languages you dictate in, and whether Ara should rewrite as well as transcribe. Neither names a model: the answers are what you know about yourself, not what you know about speech recognition. The first one decides which model gets downloaded, so it is asked before the download rather than after.

## Fixed

**Ara no longer says "thank you" to silence.** Whisper was trained on captioned video, so an empty recording comes back as "Thank you." or "Thanks for watching!" — confident, well-formed and invented. Ara had the evidence to catch it and threw it away: it only checked whether the microphone heard anything *after* deciding the transcript was blank, so the moment a hallucination arrived, the audio was never consulted. The recording is now weighed first.

Parakeet does not have this failure mode at all — a transducer emits silence during silence — so this mostly protects the Whisper path.

**The Cleanup menu applies immediately.** Picking an intensity saved the setting and moved the checkmark, and the running daemon carried on at whatever it started with until the next launch. It now applies to the next utterance, and loads the language model if the level you picked needs one.

## Install

Download, open the DMG, drag Ara to Applications, double-click. Signed and notarized since 0.4.1, so no right-click needed.

Existing installs keep their settings. Your current model and cleanup level are respected — the new defaults apply to configs that never said.
