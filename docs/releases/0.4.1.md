Ara is signed and notarized now. That fixes the first launch, and two things that were never obviously about signing at all.

## Signed and notarized

**It opens with a double-click.** No more right-click → Open, and no warning about an unidentified developer.

**Your permissions survive an update.** macOS files the microphone and accessibility grants against the app's code signature. Every unsigned build had a different one, so every update arrived as a stranger and asked for both again. A Developer ID is stable, so the grants stay.

**The model no longer recompiles after an update.** Same cause: the Neural Engine cache is keyed on the signature too, so each new build spent two and a half minutes compiling a model it had already compiled. Measured on the first notarized install: none of it. Straight from the permission grant to working dictation.

## Fixed

**Ara no longer disappears while asking for a permission.** Granting accessibility used to restart the app — the window vanished, nothing was on screen for a few seconds, and a new window appeared. It read as a crash, and one report described it exactly that way.

That restart existed because of a belief, stated in ara's own setup since the beginning, that macOS only tells a fresh process about a new grant. Measured with a probe: it is not true. `AXIsProcessTrusted` flips inside the running process about a second after the switch. Ara now carries on in place, and the same window walks from the first permission through to dictation. The restart survives as a button, for the case where the hotkey stays dead anyway.

**"Restart Ara" no longer quits ara for good.** When the button was still the main path, it asked LaunchServices to start a new copy and then exited on the next line — which cancels the request. It sometimes worked, which is worse than never.

**The Dock icon is Ara.** A bare binary has no icon and no name of its own, so the setup window arrived as a generic green "exec" tile. The app now carries the parrot, and the bundle's icon is generated from the same mark as the menu bar and the setup window rather than cropped out of the README banner.

## Install

Download, open the DMG, drag Ara to Applications, double-click. That is all of it now.
