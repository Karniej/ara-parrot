Two bugs, both reported from ordinary use, both in the same place: the optional cleanup pass that rewrites a transcript after it is transcribed. Everything here supersedes 0.5.1, which fixed one of them.

If you run with `"cleanup": "none"` — the default since 0.5.0 — none of this ever affected you.

## Fixed

**Cleanup no longer types a sentence you did not say.** Dictating "am I running the newest version" came back as "are you running the newest version". Every time, and only with cleanup switched on.

The model is not answering the question, it is paraphrasing — so the prompt's existing guard, *"a question in the transcript is a question to punctuate, not to answer"*, never applied. What drives it is the instruction that every transcript needs at least some change: on a sentence that arrives already clean, the cheapest change available is the pronoun.

**Cleanup no longer translates.** Dictating in Polish produced English. Measured on the shipped model: "czy ja używam najnowszej wersji" came back as "Am I using the latest version?", while two longer Polish sentences survived intact. Short utterances get pulled into whatever language the instructions are written in.

## Why neither was fixed in the prompt

This is the interesting part, and it is measured rather than argued.

**For the pronoun**, a rule with a worked example was added and measured on the prompt harness at all three intensities. It corrected the exact shape in the example and nothing else: with "am I late" in the prompt, "am I running the newest version" came out right, and "should I cancel the meeting or move it" still came back as "should you".

**For the translation**, asking made it actively worse. Adding *"write the rewrite in the same language the transcript is in; never translate"* turned one translated case into three, and turned one of those into an answer — "no dobra teraz dyktuję ten sam prompt…" came back as "No, you're not doing well with this prompt. Let's try again." That line was reverted.

So both checks moved to where they do not depend on the model's cooperation. `OutputGuard` already discarded rewrites that were implausible — answered rather than rewritten, verbatim duplication, refusals — and fell back to the raw transcript. These are the fourth and fifth shapes of the same failure, and none of the existing three could see either: the length is right, nothing is duplicated, neither is a refusal, and most of the words are the same.

**The person check** keys on the pair — first person leaving *and* second person arriving — because either alone is a legitimate edit. "I think we should fix the login bug" → "We should fix the login bug" drops the pronoun and adds no "you"; that is tightening, and `high` is licensed to do it. "Are you coming to dinner" is second person because you made it so.

**The translation check** is word overlap, which is the one thing that separates a cleanup from a translation in any language pair without knowing either language: a cleanup keeps your words and changes their punctuation and order, a translation keeps almost none of them. No language identification, no model, no list of languages to maintain. Diacritics are folded first, because cleanup legitimately *restores* them — "wlasciwie" and "właściwie" are the same word.

The visible result of both: the occasional sentence arrives unpolished rather than rewritten into something you did not say. It costs that utterance its cleanup. It means Ara never types words you did not speak.

The prompt rule for person stays as well, at `light` and `medium`. It does not generalise, but it reduces how often the guard has to fire, and a rewrite that never flips is better than one caught afterwards.

## Also

**The prompt measurement harness works again.** `scripts/cleanup-eval` copied four sources from paths that moved when the portable engine was split into `AraEngine`. It failed with four `cp: no such file` lines and then produced no prompts — loud, but easy to read past if you are looking at the end of the output for a score. Anything measured with it between that split and now was measuring nothing.

Harness scores against the 0.5.0 baseline, on sentences none of the prompts contain: light 12/15 → 13/15, medium 10/15 → 11/15, high 11/15 → 12/15.
